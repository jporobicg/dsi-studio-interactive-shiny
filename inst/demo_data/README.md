# DSI Studio Demo Data

This folder contains example fisheries data for demonstration purposes only.

## Files

- `Thai_main_groups.csv` - Main groups data (Anchovy, Demersal, Pelagic)
  - Columns: year, group, yield, effort, cpue
  - 3 groups, 1971-2024, no NAs

- `all_species_combined.csv` - Species × fleet data
  - Columns: species, gear, year, catch, effort, cpue
  - 8 species × 6 gears, 1971-2023
  - Effort unique per gear × year
  - Some missing CPUE (especially 2019-2023)

## Usage

These are EXAMPLE DATA ONLY for testing and demonstration. Do not use for actual stock assessments without verification.

In the DSI Studio app, these datasets are available as built-in examples via the "Load Demo Data" button.
